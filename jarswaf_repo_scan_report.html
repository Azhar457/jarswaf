Key Structural & Architecture Risks

  • [HIGH] Massive Disk Bloat (14.9 GB Build Cache): Build output and 5 raw temp dumps (600MB+ each) consume 95%+ of repository footprint. Add clean scripts or run cargo clean.
  • [HIGH] Embedded Sub-Git Repositories in external/: 6 external tool/rule repositories retain active .git directories inside external/, creating nested repository conflicts.
  • [MEDIUM] Module Naming Ambiguity in Rust Source: Multiple filename collisions (e.g. src/config.rs vs src/controller/handlers/config.rs, src/metrics.rs vs src/agent/metrics.rs) make navigation confusing.
  • [LOW] Shell Script Maintenance Overhead: manager.sh (1,200+ lines of Bash) duplicates logic across deployment, certificate renewal, and testing.
